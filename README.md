# Law Memory Agent

A Python-based AI agent project focused on memory and contextual behavior for domain-specific reasoning.

## Overview
This repository contains a lightweight agent architecture with memory support, designed to retain context and support task-oriented interactions. It is structured as a small experimental project for building memory-aware AI behavior.

## Project Structure
- `agent.py` - core agent logic
- `memorySystem.py` - memory handling
- `mian.py` - project entry point
- `requirements.txt` - project dependencies
- `.gitignore` - ignored files

## Features
- Agent-based workflow
- Memory support
- Lightweight experimentation environment
- Context-aware interaction design

## Getting Started
1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the project:

```bash
python mian.py
```

## Notes
This project is useful for testing memory-enabled AI behavior in a small and flexible codebase.
